## Security posture

Meeting Prepper is a single-operator Express + SQLite dashboard with a separate bearer-gated MCP process. The main HTTP app has no application authentication. That matches a personal local tool, not a multi-tenant SaaS. The remaining issues are (1) unescaped HTML and open redirects on the view layer, (2) missing same-origin binding on mutations, (3) listen-on-all-interfaces defaults, (4) webhook HMAC over re-serialized JSON, and (5) known-vulnerable lockfile versions of vite, hono, and undici.

### html-search-reflected-xss-title (high)

- **Location:** `src/routes/views.ts` `GET /search` → `renderLayout` → `src/views/layout.html` `<title>`.
- **Lower-trust principal:** anyone who can cause the operator browser to open `/search?q=...`.
- **Reproduction:** source string replace of `</title><script>...` into the layout; do not hit a live host.
- **Conditions:** unauthenticated view; no CSP.
- **Result:** markup is not entity-encoded in the title slot.
- **Impact:** script on the app origin can call `/api` and drive configured integrations.
- **Fix:** `escapeHtml(title)` in `renderLayout`.

### html-action-item-open-redirect (medium)

- **Location:** `src/routes/views.ts` `POST /action-items/:id/status`.
- **Lower-trust principal:** HTTP client that can POST the form.
- **Reproduction:** `redirect=https://attacker.example/phish` in the urlencoded body; Express `res.redirect` copies it to `Location`.
- **Fix:** allow only same-app relative paths (`/` but not `//`).

### lockfile-vite-7.3.3 / lockfile-hono-4.12.12 / lockfile-undici-7.25.0 (low)

- **Location:** `package-lock.json` `node_modules/{vite,hono,undici}`.
- **Result:** resolved versions 7.3.3, 4.12.12, 7.25.0.
- **Fix:** npm overrides for vite 7.3.8 and undici 7.30.2. Do not duplicate the existing `cursor/bump-hono-4-13-16-1deb` hono override.

## Hardening notes and positive patterns

- MCP server fail-closes without `MCP_SERVER_TOKEN` and uses a length-then-XOR bearer compare.
- Linear webhook HMAC uses `timingSafeEqual` and rejects missing signatures.
- SQLite access uses bound parameters; search/action-item filters are allowlisted or LIKE-escaped.
- `gog` is invoked with `execFile` argv and `--no-input`, not a shell string.
- Follow-up email path is documented as draft-only.
- Error handler hides 500 stacks from clients.
- `.gitignore` covers `.env` and `data/`.
- No committed secrets were found in source (dummy values in tests only).

Suggested hardening (not findings): CSP/`frame-ancestors`, JSON body size limit on the main app, bind `127.0.0.1` by default, Origin check on mutations, HMAC over raw webhook bytes.
